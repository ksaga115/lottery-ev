# 抽選会 期待値ナビ

福引き・○○本引きなどの抽選会で、**先に引いた人の結果を聞きながらその場で期待値を計算し直す**スマホ向けWebアプリです。

## ▶ アプリを開く

**https://ksaga115.github.io/lottery-ev/**

スマホのブラウザで開いて「ホーム画面に追加」しておくと、会場ですぐ使えます。

## できること

- **次の1本の期待値**を画面上部に常に大きく表示（参加費との差・還元率・推移グラフつき）
- 当たりが発表されたら、その賞の「出た」をタップするだけで残り本数と期待値を更新
- 「残り◯本です」「◯人引きました」のような発表は人数・残り本数の入力で反映
  （記録した当たり以外は「残り全部」の賞＝ハズレ・最下位賞として数えます）
- **自分の順番**を入れると
  - 自分の番に上位賞が1本以上残っている確率
  - 自分の番での期待値がどの範囲に動きそうか（1,000回シミュレーション）
- **確率の内訳**（超幾何分布・負の超幾何分布）
  - 自分の1回で「¥◯以上」が出る確率と、金額のばらつき（標準偏差）
  - 各賞が次に出るまでの平均人数と、50%の確率で出る人数
  - 自分の番までに各賞が何本出そうか（平均・80%の範囲・分布グラフ）
- **当たりの偏り推定**（ベイズ推定）
  - 運営が上位賞を後半に残している・箱がよく混ざっていない、などの「実際の抽選の偏り」を、ここまでの出方から推定
  - 偏り係数 w（1 = 公平、1未満 = 上位賞が後に残されている）とその事後分布を表示し、偏りを考えに入れた期待値を出す
  - 推定には引き終わった人数（または残り本数）の入力が必要
- 「1つ戻す」「−」で押し間違いを取り消し（取り消した記録は履歴からも消えます）
- メイン画面からも記録をリセット（2回タップで実行）
- 時刻つきの記録と期待値の推移グラフ
- 賞の金額・本数は自由に追加・削除でき、**テンプレートとして保存**して別の抽選会でも使える
- 設定はJSONで書き出し・取り込み可能（他の端末や人と共有するとき用）

データはすべてその端末のブラウザ（localStorage）に保存されます。サーバーには何も送りません。

## 初期テンプレート

三井アウトレットパーク岡崎「1,111本引き」（2026/10/11・10/12）をもとにしています。

| 賞 | 金額 | 本数 |
| --- | ---: | ---: |
| 特賞 | ¥100,000 | 1 |
| 1等 | ¥50,000 | 2 |
| 2等 | ¥20,000 | 12 |
| 3等 | ¥10,000 | 40 |
| 4等 | ¥6,000 | 残り全部 |

- 2日間で合計1,111本。**10/11（日）は555本**（4等 500本）、10/12（月祝）は残りの556本として登録しています
- 特賞〜3等の本数は各日ごと
- 参加費 ¥5,000。10/11の開始時点の期待値は約 ¥6,919（還元率 約138%）

当日の発表と違ったら設定画面で直してください。2日目は設定 → テンプレートから「10/12（月祝）」を読み込めば始められます。

## 計算のしかた

- 期待値 = Σ(残りの本数 × 金額) ÷ 残りの総本数
- 自分の番までに何が出るかは分からないので、今の時点で見た「自分の番の期待値」は今の期待値と同じになります
- 自分の番に賞が残っている確率は超幾何分布（残り k 本がすべて前の m 人に引かれる確率 = C(m,k)/C(R,k)）から計算しています
- 自分の番までに出る本数は超幾何分布 P(X=x) = C(k,x)·C(R−k,m−x)/C(R,m)、次に出るまでの平均人数は負の超幾何分布の期待値 (R+1)/(k+1) です
- 偏り推定: 上位賞1本が引かれやすさを w 倍とし、「n人中 x本」を Fisher の非心超幾何分布 P(x) ∝ C(K,x)·C(B,n−x)·w^x に当てはめ、事前分布 log w ~ N(0, 0.5²) でベイズ推定。自分の番までに残る上位賞の本数は Wallenius の平均式で求めています
